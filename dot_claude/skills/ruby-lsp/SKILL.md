# ruby-lsp

When the project includes the `ruby-lsp` gem, use the ruby-lsp plugin in Claude Code to leverage LSP capabilities.

## Capabilities

- List classes, methods, and constants in a file
- Jump to symbol definitions
- Find all usages of a symbol
- Get type info and documentation for a symbol
- Search symbols across the project
- Find implementations of an interface
- Trace call hierarchy
